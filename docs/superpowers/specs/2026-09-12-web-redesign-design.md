# ออกแบบหน้าตาใหม่ ให้เป็นเว็บที่ใช้งานได้จริง (2026-09-12)

## ปัญหา (ดูจากหน้าเว็บจริงที่จอ 1440×900 และ 390×844)

1. บนคอมพิวเตอร์ แอปเป็นคอลัมน์กว้าง 560 px กลางจอ ด้านข้างว่างเกือบ 2 ใน 3 ของจอ ดูเป็นมือถือจำลอง ไม่ใช่เว็บ
2. ไม่มีแถบเมนูด้านบนแบบเว็บ มีแต่แถบแท็บด้านล่างแบบแอปมือถือ ตัวหนังสือเล็กมาก
3. ไอคอนเป็น emoji (🏠 🗺️ 🛣️ ✏️ 🚗) หน้าตาต่างกันตามเครื่อง ดูไม่เป็นงานจริง
4. ใช้ฟอนต์ของระบบ ภาษาไทยบน Windows ออกมาเป็นฟอนต์เก่า
5. การ์ดแบนราบ ขอบเทาบาง ไม่มีเงา ไม่มีสถานะตอนเอาเมาส์ชี้ ลำดับความสำคัญของตัวหนังสือแยกไม่ออก
6. แผนที่ถูกบีบอยู่ในคอลัมน์แคบ ทั้งที่เป็นหัวใจของแอป เว็บแผนที่จริง (Google Maps, Longdo Map) ใช้แผงรายการด้านซ้าย + แผนที่เต็มจอ
7. หน้าแรกเป็นข้อความเรียงลงมา ไม่มีส่วนเปิด (hero) ไม่มีตัวเลขสรุป ไม่มีภาพแผนที่

## เป้าหมาย

- บนคอมพิวเตอร์ (กว้างตั้งแต่ 900 px): หน้าตาแบบเว็บ มีแถบเมนูด้านบนทุกหน้า ใช้ความกว้างเต็มจอ
- บนมือถือ: หน้าตาแบบแอปจริง ไอคอนเส้นชุดเดียวกัน หัวหน้าจอสะอาด
- ฟีเจอร์ ข้อมูล และกติกาเดิมอยู่ครบ (ห้ามสีเขียว ห้ามแต่งสถิติ ป้ายยืนยัน/ไม่ยืนยัน)
- ยังเป็น React Native ตัวเดียวกัน รันบน Snack / Expo Go ได้เหมือนเดิม

ไม่ทำ: เปลี่ยนแผนที่เป็นของเจ้าอื่นที่ต้องใช้ API key (CARTO ต้องขอ key ถ้าไม่มีจะขึ้นลายน้ำ ห้ามซ่อน)

## เทคนิค

- แถบเมนูบนอยู่นอกตัวนำทาง (App.js) จึงอยู่ครบทุกหน้ารวมหน้ารายละเอียด ใช้ navigationRef สั่งเปลี่ยนหน้า
  (React Navigation 7 ต้องส่ง `{ pop: true }` ไม่อย่างนั้น navigate จะซ้อนหน้า MainTabs ใหม่)
- จอกว้างซ่อนแถบแท็บล่างและหัวของ native-stack แล้วแสดงปุ่มย้อนกลับในหน้าแทน
- โหลดฟอนต์และไอคอนก่อนแสดงแอป (หน้าจอพื้นกรมท่าสั้น ๆ) ถ้าโหลดไม่ได้ก็แสดงด้วยฟอนต์ระบบต่อ ไม่ค้าง
- CSS เฉพาะเว็บใน public/index.html: พื้นหลังหน้า แถบเลื่อนบาง ปรับสีแผ่นแผนที่ OSM ให้นุ่มลงให้หมุดเด่น ป้ายชื่อหมุดใช้ฟอนต์เดียวกับแอป
- เทสต์ใหม่: utils/layout.js (จุดตัดจอ จำนวนคอลัมน์) และตรวจว่าทุก `COLORS.xxx` / `TEXT.xxx` ที่โค้ดเรียกมีอยู่จริง

## การตรวจ

ถ่ายภาพหน้าจอจริงทุกหน้าที่ 1440×900 และ 390×844 เทียบก่อน/หลัง กดผ่านทุกเส้นทางการใช้งานเดิม
(ค้นหา เปิดรายละเอียด รายการโปรด วางแผนเส้นทาง จำลองการเดินทาง บันทึก/ลบจุด ออฟไลน์) ไม่มี error ใน console
แล้ว build Android และตรวจ Snack
