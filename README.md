## ⚠️ อ่านก่อนใช้งาน: ข้อมูลสถิติยังไม่ได้กรอก

ไฟล์ `data/riskPoints.json` มี **พิกัดจริง 12 จุด** แต่ตัวเลขสถิติอุบัติเหตุยัง **ว่างเปล่า**
ทุกจุดตั้ง `verified: false` และ `source` เขียนว่า `⚠️ รอกรอกข้อมูลจริง`

เป็นแบบนี้โดยตั้งใจ ตามกฎที่ทีมเขียนไว้เองในเอกสารบทที่ 6.3:
**ห้ามบันทึกตัวเลขสถิติที่ปราศจากแหล่งอ้างอิง**

แอปทำงานได้ครบทุกฟีเจอร์ จุดที่ยังไม่มีสถิติจะได้คะแนน 0 = หมุดเหลือง + ป้าย "⚠️ ยังไม่ยืนยัน"
เมื่อลงพื้นที่เก็บข้อมูลจริงแล้ว ให้เติม `incidents`, `peakMonths`, `peakHours`, `advice`, `source`
แล้วเปลี่ยน `verified` เป็น `true` คะแนนกับสีหมุดจะเปลี่ยนตามเอง ไม่ต้องแก้โค้ด

## วิธีรัน

### บนมือถือ (แนะนำ — แผนที่สมบูรณ์ที่สุด)
1. ติดตั้งแอป **Expo Go** จาก Play Store / App Store
2. เปิด Snack ของโปรเจค แล้วสแกน QR code

### บนเว็บผ่าน Snack
กดแท็บ **Web** ใน Snack ได้เลย — แผนที่จะใช้ Leaflet แทน react-native-maps โดยอัตโนมัติ

### รันบนเครื่องตัวเอง
```bash
npm install
npx expo start
```
กด `w` เพื่อเปิดบนเว็บ หรือสแกน QR code ด้วย Expo Go

### รันเทสต์คณิตศาสตร์ (ไม่ต้องใช้ Snack ไม่ต้องต่อเน็ต)
```bash
npm test
```
ต้องได้ `pass 64` `fail 0`

| โฟลเดอร์ | หน้าที่ | ทดสอบ |

| `screens/` | 6 หน้าจอของแอป | ทดสอบตอนรันแอป |
| `navigation/` | ผูกหน้าจอเข้าด้วยกัน | ทดสอบตอนรันแอป |

### กติกาที่ต้องรู้ก่อนแก้โค้ด

**1. นามสกุล `.js` ในบรรทัด import ไม่เหมือนกันแต่ละโฟลเดอร์ — ตั้งใจให้เป็นแบบนั้น**
- `utils/` กับ `tests/` **ต้องใส่** `.js` เพราะ Node รันตรง ๆ และ Node ไม่เติมนามสกุลให้
- `hooks/`, `components/`, `screens/`, `navigation/` **ห้ามใส่** เพราะ Metro เติมให้เอง

**2. แผนที่มีสองไฟล์ ห้ามแก้ไฟล์เดียว**
`AppMap.native.js` (มือถือ) กับ `AppMap.web.js` (เว็บ) ต้องรับ props ชุดเดียวกันเสมอ
Metro เลือกไฟล์ให้อัตโนมัติ หน้าจอเขียนแค่ `import AppMap from '../components/AppMap'`
`react-native-maps` ใช้บนเว็บไม่ได้ จึงต้องอยู่ใน `.native.js` เท่านั้น

**3. ห้ามมีสีเขียวใน `RISK_LEVELS`**
การไม่มีหมุดแปลว่า "ยังไม่มีข้อมูล" ไม่ได้แปลว่า "ปลอดภัย" — มีเทสต์คุมไว้แล้ว

**4. ค่าคงที่ในการคิดคะแนนห้ามแก้มั่ว**
`N_MAX=30`, `SEASON_PEAK=1.3`, `TIME_PEAK=1.1` ถอดมาจากม็อกอัพของทีม
มีเทสต์ชื่อ "ตรงกับม็อกอัพ" คุมไว้ว่าเขาคอหงส์ต้องได้ 43 พอดี ถ้าแก้แล้วเทสต์จะแดง
